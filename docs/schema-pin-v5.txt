# 🔌 Schema Collegamenti Arduino Mega V5 - RoboCup Rescue Maze 2026

## 📋 MOTORI - Driver A (Ruote Anteriori)

### Motor Front Left (FL)
- **PWM 6** → Driver A - ENA (Velocità motore anteriore sinistro)
- **Pin 22** → Driver A - IN1 (Forward)
- **Pin 23** → Driver A - IN2 (Backward)

### Motor Front Right (FR)
- **PWM 7** → Driver A - ENB (Velocità motore anteriore destro)
- **Pin 24** → Driver A - IN3 (Forward)
- **Pin 25** → Driver A - IN4 (Backward)

---

## 📋 MOTORI - Driver B (Ruote Posteriori)

### Motor Back Left (BL)
- **PWM 8** → Driver B - ENA (Velocità motore posteriore sinistro)
- **Pin 26** → Driver B - IN1 (Forward)
- **Pin 27** → Driver B - IN2 (Backward)

### Motor Back Right (BR)
- **PWM 9** → Driver B - ENB (Velocità motore posteriore destro)
- **Pin 28** → Driver B - IN3 (Forward)
- **Pin 29** → Driver B - IN4 (Backward)

---

## 📋 ALIMENTAZIONE DRIVER MOTORI

### Driver A (Anteriori)
- **VCC** → 5V Arduino (logica)
- **GND** → GND comune (Arduino + Batteria)
- **12V** → Batteria 12V (potenza motori)

### Driver B (Posteriori)
- **VCC** → 5V Arduino (logica)
- **GND** → GND comune (Arduino + Batteria)
- **12V** → Batteria 12V (potenza motori)

⚠️ **IMPORTANTE**: Tutti i GND (Arduino, Driver A, Driver B, Batteria) devono essere collegati insieme!

---

## 📋 SENSORI DISTANZA VL53L0X (x3)

Tutti e 3 i sensori usano il **bus I2C**:
- **SDA** → Pin 20 Arduino Mega
- **SCL** → Pin 21 Arduino Mega
- **VCC** → 5V Arduino
- **GND** → GND Arduino

### Indirizzi I2C (configurati via software):
- **VL53L0X Front**: 0x30
- **VL53L0X Right**: 0x31
- **VL53L0X Left**: 0x32

---

## 📋 SENSORE COLORE TCS3200

- **S0** → Pin 30 (Frequency scaling)
- **S1** → Pin 31 (Frequency scaling)
- **S2** → Pin 32 (Color filter)
- **S3** → Pin 33 (Color filter)
- **OUT** → Pin 34 (Frequency output)
- **VCC** → 5V Arduino
- **GND** → GND Arduino

---

## 📋 SENSORE INCLINAZIONE MPU6050

Usa il **bus I2C** (condiviso con VL53L0X):
- **SDA** → Pin 20 Arduino Mega
- **SCL** → Pin 21 Arduino Mega
- **VCC** → 5V Arduino
- **GND** → GND Arduino

**Indirizzo I2C**: 0x68

---

## 📋 SERVO MOTORI

### Servo Camera (rotazione camera Raspberry)
- **Signal** → PWM 10
- **VCC** → 5V Arduino
- **GND** → GND Arduino

### Servo Medikit (rilascio medikit)
- **Signal** → PWM 11
- **VCC** → 5V Arduino
- **GND** → GND Arduino

---

## 📋 LED STATUS

- **LED bianco** → Pin 13 (con resistenza 220Ω)
- **GND** → GND Arduino

Funzioni:
- Lampeggio 5s quando vittima rilevata
- ON fisso quando sistema attivo
- OFF quando sistema in emergency stop

---

## 📋 COMUNICAZIONE RASPBERRY PI

Usa **Serial1** (seconda porta seriale Arduino Mega):
- **TX1 (Pin 18)** → RX Raspberry Pi
- **RX1 (Pin 19)** → TX Raspberry Pi
- **GND** → GND comune (Arduino + Raspberry)

**Baud rate**: 9600

⚠️ **NOTA**: Serial (USB) è usata per debug su computer, Serial1 per comunicazione con Raspberry.

---

## 📋 ALIMENTAZIONE GENERALE

### Arduino Mega 2560
- **Vin** → Batteria 12V (o alimentatore 7-12V)
- **GND** → GND comune

**Oppure**:
- **USB** → Durante programmazione/debug
- **Jack DC** → Alimentatore esterno 7-12V

### Raspberry Pi
- **5V GPIO** → Alimentazione dedicata 5V (consigliato power bank o alimentatore separato)
- **GND** → GND comune con Arduino

⚠️ **NON alimentare Raspberry dai 5V dell'Arduino!** Consuma troppa corrente.

## ⚡ NOTE IMPORTANTI

### 1. GND Comune (CRITICO!)
Tutti i GND devono essere collegati insieme:
- GND Arduino
- GND Driver A
- GND Driver B
- GND Batteria 12V
- GND Raspberry Pi
- GND sensori e servo

**Senza GND comune il sistema NON funzionerà correttamente!**

---

### 2. Alimentazione Motori
- Driver A e B: **12V dalla batteria** per i motori
- Driver A e B: **5V dall'Arduino** per la logica
- **Non invertire** 12V e 5V!

---

### 3. Pin PWM Disponibili Arduino Mega
Pin usati per PWM:
- **6, 7, 8, 9**: Motori
- **10, 11**: Servo

Altri pin PWM liberi (se servono): 2, 3, 4, 5, 12, 44, 45, 46

---

### 4. Bus I2C Condiviso
I2C (SDA 20, SCL 21) è condiviso tra:
- 3x VL53L0X (indirizzi diversi)
- 1x MPU6050

Ogni dispositivo ha indirizzo univoco, quindi non ci sono conflitti.

---

### 5. Tensione Logica
- Arduino Mega: **5V logic**
- Raspberry Pi: **3.3V logic**

Per comunicazione UART (TX/RX):
- **Arduino TX → Raspberry RX**: Serve divisore di tensione (5V → 3.3V)
- **Raspberry TX → Arduino RX**: Funziona direttamente (3.3V è sufficiente per 5V logic)

**Divisore di tensione per TX Arduino → RX Raspberry:**
```
Arduino TX1 (5V) ──┬── Resistenza 1kΩ ──┬── Raspberry RX (3.3V)
                   │                    │
                   └── Resistenza 2kΩ ──┴── GND
```

---

### 6. Ordine di Accensione Consigliato
1. Collega batteria 12V
2. Accendi Arduino Mega (Vin o USB)
3. Verifica LED power Arduino acceso
4. Accendi Raspberry Pi
5. Attendi boot Raspberry (~30 secondi)
6. Avvia script Python su Raspberry
7. Arduino e Raspberry iniziano comunicazione

---

### 7. Test Iniziale
Prima di montare tutto sul robot:

1. **Test motori singoli**:
   - Carica sketch Arduino
   - Apri Serial Monitor (9600 baud)
   - Commenta `loop()` e decomenta `testSingleMotors()` in setup
   - Verifica che ogni motore ruoti correttamente

2. **Test sensori**:
   - Verifica valori VL53L0X (distanze in mm)
   - Verifica valori TCS3200 (colori)
   - Verifica valori MPU6050 (pitch in gradi)

3. **Test comunicazione**:
   - Collega Raspberry Pi
   - Avvia script Python
   - Verifica messaggi scambiati via Serial Monitor
