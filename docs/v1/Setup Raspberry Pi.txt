Setup Raspberry Pi

1. Installa Raspberry Pi OS
```bash
# Scarica Raspberry Pi Imager
# Installa Raspberry Pi OS (64-bit, desktop)
# Abilita SSH e configura WiFi
```
2. Aggiorna sistema
```bash
sudo apt update
sudo apt upgrade -y
```
3. Installa dipendenze
```bash
# Python 3 e pip
sudo apt install python3 python3-pip -y

# OpenCV
sudo apt install python3-opencv -y

# Librerie Python
pip3 install pyserial numpy

# Tesseract OCR (per lettere greche)
sudo apt install tesseract-ocr tesseract-ocr-ell -y
pip3 install pytesseract
```
4. Configura porta seriale
```bash
# Aggiungi user a gruppo dialout
sudo usermod -a -G dialout $USER

# Logout e re-login per applicare
```
5. Trova porta Arduino
```bash
# Con Arduino connesso
ls /dev/ttyACM*
```
6. Testa installazione
```bash
cd /home/pi/robocup
python3 test_setup.py
```

Setup Arduino
1. Installa Arduino IDE
Scarica da arduino.cc
Installa su PC di sviluppo
2. Installa librerie
Vai su Sketch → Include Library → Manage Libraries...
Cerca e installa:
`VL53L0X` by Pololu
`LiquidCrystal I2C` by Frank de Brabander
`MPU6050` by Electronic Cats
`Servo` (già inclusa)
`Wire` (già inclusa)
3. Carica sketch
Apri `arduino_v1.ino` o `arduino_v2.ino`
Seleziona Tools → Board → Arduino Mega 2560
Seleziona Tools → Port → [porta corretta]
Clicca Upload (→)
4. Verifica funzionamento
Apri Serial Monitor (Ctrl+Shift+M):
Baud rate: 115200
Dovresti vedere log inizializzazione
